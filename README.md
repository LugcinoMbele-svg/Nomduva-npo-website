# Nomduva Community Empowerment Project (NCEP) - Official Website

Welcome to the official repository for the **Nomduva Community Empowerment Project (NCEP)** website. NCEP is a registered South African Non-Profit Organisation (308-012 NPO) dedicated to youth empowerment, creative arts development, leadership training, and social transformation in Hammarsdale and surrounding townships in KwaZulu-Natal.

---

## 📌 Project Overview

This repository hosts the front-end code for the official NCEP website. It provides community members, youth participants, donors, and corporate sponsors with clear access to information regarding our flagship programmes, past projects, leadership team, and impact metrics.

### Key Features
* **Multi-Page Site Architecture:** Fully responsive static pages detailing our mission, leadership, past events, and metrics.
* **Interactive Forms:** Dedicated forms for youth/student registrations and corporate/sponsor inquiries.
* **Featured Project Showcase:** Highlights key initiatives including the flagship **Ikhaya Golden Mic** talent platform.
* **Mobile-Responsive Design:** Lightweight, fast-loading design optimized for mobile and desktop browsing.
